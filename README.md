# Data-Structure-Projects
A collection of projects that solve different problems from my csharp data structures coursework

- Implemented core data structures from first principles in C#, including an array-backed stack with automatic resizing and a binary search tree with full deletion handling, applied to a browser-history manager.
- Built a custom stack and binary search tree (no built-in collections) to model and index web navigation history.
- Developed an in-place Insertion Sort engine in C# with System.Text.Json parsing and multi-criteria sorting for an online bookstore.
